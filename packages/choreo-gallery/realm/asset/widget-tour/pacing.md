# Choreo tour — editorial interest and pacing

Scores are editorial judgments of visual payoff, distinctiveness, and explanatory value—not API quality. All 45 demos are included. George’s narration overlaps camera travel.

Estimated tour: 5.5 minutes, plus loading delays. Most stops last 4–8 seconds.

Native clicks, presses, scrolling, and playhead scrubbing operate the demos. Keyframes already runs continuously. Pause or touch a demo to take over.

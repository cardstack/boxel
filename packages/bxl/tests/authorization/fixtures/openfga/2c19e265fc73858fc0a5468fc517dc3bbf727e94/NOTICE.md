# OpenFGA test fixture notice

The YAML files in this directory are unmodified test fixtures copied from
[`openfga/openfga`](https://github.com/openfga/openfga) at commit
`2c19e265fc73858fc0a5468fc517dc3bbf727e94`.

They are retained solely as a pinned semantic-conformance corpus for BXL's
synchronous authorization kernel. Their source paths and byte hashes are
recorded in `manifest.json`.

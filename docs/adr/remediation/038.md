# ADR 038 remediation

Places where the code does not meet [ADR 038](../038-narrow-policy-grants-by-path-and-keep-every-grant-typed.md)
yet (ADR 001 §1.6). Each entry names a file by its path from the repository
root, in backticks, and the requirement it breaks.

- `packages/runtime-common/card-operations/dispatch.ts` (`resolveAndGate`)
  resolves the operation against a stored target's type, which reads the
  target's index row, before the gate matches any grant. A target that no
  grant for the invoked operation covers still costs that read, which breaks
  §1.3.
- `packages/runtime-common/card-operations/gate.ts` (`decide`) reads a card's
  index row before it loads the policy, and a file's stored bytes before it
  matches any grant. A target that no grant for the invoked operation covers
  still costs that read, which breaks §1.3.

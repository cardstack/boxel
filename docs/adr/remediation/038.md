# ADR 038 remediation

Places where the code does not meet [ADR 038](../038-match-file-paths-with-path-aware-globs-and-cap-the-file-content-the-index-holds.md)
yet (ADR 001 §1.6).

- `packages/runtime-common/query-engine/filter-compiler.ts`
  (`#patternCondition`, the SQLite path) breaks §1.1. The browser's SQLite
  index runs a glob as `LIKE` only, so `*` and `?` cross `/` there. The
  difference is listed in `docs/search.md` (ADR 033 §1.1). Match by segment,
  or refuse the glob with `needs-postgres`.

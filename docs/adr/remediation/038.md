# ADR 038 remediation

Places where the code does not meet [ADR 038](../038-narrow-policy-grants-by-path-and-keep-every-grant-typed.md)
yet (ADR 001 §1.6). Each entry names a file by its path from the repository
root, in backticks, and the requirement it breaks.

- `packages/runtime-common/card-operations/dispatch.ts` (`resolveAndGate`)
  resolves an operation a type may declare against a stored target's type,
  which reads the target's index row, before the gate matches a grant's
  paths. The base a declaration builds on decides whether the target's own
  path or a create's landing is matched, so the paths are matched before
  that read only for the card verbs and a definition-free operation, and
  only for a caller who may not read the realm. Any other target whose path
  no grant for the invoked operation covers still costs that read, which
  breaks §1.3.
- `packages/runtime-common/card-operations/policy.ts` (`RealmPolicyCache`)
  compiles a realm's policy again only when the policy card or a module its
  rules name changes, not when the realm's settings change, which breaks §1.4.

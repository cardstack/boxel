# ADR 037 remediation

Places where the code does not meet [ADR 037](../037-name-a-set-of-realm-paths-with-a-list-of-literal-whole-segment-prefixes.md)
yet (ADR 001 §1.6). Each entry names a file by its path from the repository
root, in backticks, and the requirement it breaks.

- `packages/runtime-common/realm-history.ts` (`ReadHistoryParams.paths`)
  defines its own syntax for history path filters, which breaks §1.1.

`packages/realm-historian/src/reader.ts`:

- `readPath` and `pathFilters` parse history path filters with their own
  rules, which breaks §1.1 and §1.5: they don't decode percent-escapes, and
  they accept backslashes, `*`, `:`, `?`, `#` and control characters other
  than NUL and newline.
- `matchesAny` matches them with its own rule, which breaks §1.1 and §1.4: a
  file filter also matches everything under a directory of the same name.

# ADR 019 remediation

Places where the code does not meet [ADR 019](../019-build-the-secure-origins-pages-as-their-own-ember-app-on-pret-ui.md)
yet (ADR 001 §1.6). Each entry names a file by its path from the repository
root, in backticks, and the requirement it breaks. Write "No known gaps." when
there are none.

The package keeps its own component for a job a Pret UI component that can
ship does, which breaks §1.11:

- `packages/secure-origin/src/components/button.gts` (Pret UI's Button).

The package keeps its own helper or modifier for a job a Pret UI one that can
ship does, which breaks §1.11:

- `packages/secure-origin/src/helpers/truth-helpers.ts` (`eq`, `not`, `bool`,
  `and`, `or`, `gt`: Pret UI's `helpers.gts`).
- `packages/secure-origin/src/modifiers/autofocus.ts` (Pret UI's `focusWhen`,
  in `focus.gts`).

§1.11:

- `packages/secure-origin/src/components/icons/key-round.gts`

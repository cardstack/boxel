# ADR 019 remediation

Places where the code does not meet [ADR 019](../019-build-the-secure-origins-pages-as-their-own-ember-app-on-pret-ui.md)
yet (ADR 001 §1.6). Each entry names a file by its path from the repository
root, in backticks, and the requirement it breaks. Write "No known gaps." when
there are none.

The package keeps its own component for a job a Pret UI component that can
ship does, which breaks §1.11:

- `packages/secure-origin/src/shell/keys/workspace-dropdown.gts` (Pret UI's
  Select).

The package keeps its own copy of an icon boxel-icons has, which breaks
§1.11:

- `packages/secure-origin/src/components/icons/icon-plus.gts` (boxel-icons'
  `plus`).
- `packages/secure-origin/src/components/icons/icon-x.gts` (boxel-icons' `x`).
- `packages/secure-origin/src/components/icons/dropdown-arrow-down.gts`
  (boxel-icons' `chevron-down`).
- `packages/secure-origin/src/components/icons/dropdown-arrow-up.gts`
  (boxel-icons' `chevron-up`).
- `packages/secure-origin/src/components/icons/warning.gts` (boxel-icons'
  `triangle-alert`).
- `packages/secure-origin/src/components/icons/check-mark.gts` (boxel-icons'
  `check`).
- `packages/secure-origin/src/components/icons/success-bordered.gts`
  (boxel-icons' `circle-check`).
- `packages/secure-origin/src/components/icons/failure-bordered.gts`
  (boxel-icons' `circle-x`).

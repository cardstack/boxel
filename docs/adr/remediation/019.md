# ADR 019 remediation

Places where the code does not meet [ADR 019](../019-build-the-secure-origins-pages-as-their-own-ember-app-on-pret-ui.md)
yet (ADR 001 §1.6). Each entry names a file by its path from the repository
root, in backticks, and the requirement it breaks. Write "No known gaps." when
there are none.

The package keeps its own component for a job a Pret UI component that can
ship does, which breaks §1.11:

- `packages/secure-origin/src/components/button.gts` (Pret UI's Button).
- `packages/secure-origin/src/components/checkbox.gts` (Pret UI's Checkbox).
- `packages/secure-origin/src/components/label.gts` (Pret UI's Label).
- `packages/secure-origin/src/components/field-container.gts` (Pret UI's
  Field).
- `packages/secure-origin/src/components/radio.gts` (Pret UI's RadioGroup).
- `packages/secure-origin/src/components/radio-tile.gts` (Pret UI's
  RadioCard).
- `packages/secure-origin/src/components/disclosure-toggle.gts` (Pret UI's
  Disclosure).

# ADR 040 remediation

Places where the code does not meet [ADR 040](../040-bound-a-tabs-requests-in-flight-to-each-origin-and-send-writes-first.md)
yet (ADR 001 §1.6). Each entry names a file by its path from the repository
root, in backticks, and the requirement it breaks.

- `packages/host/app/services/host-mode-service.ts` (the head-markup
  `_federated-search` request) breaks §1.1.
- `packages/host/app/services/network.ts` (`limitedFetch`) breaks §1.2–§1.5
  while the `LIMIT_REQUESTS_IN_FLIGHT` build-time flag is off, which it is in
  production.

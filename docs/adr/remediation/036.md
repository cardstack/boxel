# ADR 036 remediation

Places where the code does not meet [ADR 036](../036-route-dynamic-host-paths-through-two-declarative-route-forms-and-one-shared-resolver.md)
yet (ADR 001 §1.6). Each entry names a file by its path from the repository
root, in backticks, and the requirement it breaks.

- `packages/runtime-common/host-route-address.ts` (`hostRouteAddress`) has
  no caller: there is no `hrefTo` helper in `packages/base` yet, so links
  keep card URLs at prerender and in the browser. Breaks §1.5.
- `packages/realm-server/handlers/serve-index.ts` injects the validated
  routes (`hostDynamicRoutes`) only into the config of a page served on a
  host URL. The prerender and interact mode have no copy of the routes, so
  the reverse lookup can't run there. Breaks §1.5.
- `packages/realm-server/handlers/serve-index.ts` serves an alias route's
  card (`"statusCode": 301`) at the alias path instead of answering 301 to
  the card's canonical address. Breaks §1.2.
- `packages/host/app/services/host-mode-service.ts` (`resolveRoutedPath`)
  resolves in-app navigation from fixed routes only and does not call
  `resolveHostRoute`. Breaks §1.3.

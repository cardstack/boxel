# ADR 022 remediation

Places where the code does not meet [ADR 022](../022-do-the-assistants-workspace-work-in-one-sandboxed-script.md)
yet (ADR 001 §1.6).

- `packages/host/app/tools/send-ai-assistant-message.ts` (`run`) breaks §1.1.
  - **Now:** when card code sends a message with attached cards, the tool adds
    a named patch tool to the message for each attached card that the user can
    write. The model can change these cards with that tool, outside the Realm
    Runner.
  - **Fix:** stop adding the patch tools, so that the model changes cards with
    `run-realm-code`.

- `packages/host/app/tools/run-realm-code.ts` (`index.reindex`,
  `index.fullReindex` and `index.invalidate`) breaks §1.6.
  - **Now:** a script can make these calls any number of times in one run.
    Each call starts an index job on the realm server. Other costly calls have
    a limit per run, for example `realm.capture` and `realm.images.generate`.
  - **Fix:** give each of these calls a maximum number of calls per run.

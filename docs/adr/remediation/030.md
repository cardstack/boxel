# ADR 030 remediation

Places where the code does not meet [ADR 030](../030-batch-ai-only-when-an-automation-opts-in-end-the-run-while-it-waits-and-bill-every-batch.md)
yet (ADR 001 §1.6).

- `packages/realm-server/handlers/handle-request-forward.ts` breaks §1.1. It accepts any realm-server token and forwards any path under a configured destination (`matchesDestination` matches by prefix), so it neither requires a run token for a batch call nor refuses batch paths. Whether OpenRouter's `/api/v1/batches` is reachable depends only on the destination's configured URL.

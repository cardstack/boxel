# ADR 030 remediation

Places where the code does not meet [ADR 030](../030-batch-ai-only-when-an-automation-opts-in-end-the-run-while-it-waits-and-bill-every-batch.md)
yet (ADR 001 §1.6).

- `packages/runtime-common/ai-batch-follow-ups.ts` breaks §1.2. A follow-up starts only at its batch's deadline, or at a resume of its paused automation: nothing starts it when the batch reaches a final state earlier, neither OpenRouter's completion webhook nor the minute tick's check of open batches.
- `packages/runtime-common/tasks/run-automation.ts` breaks §1.3. A follow-up's script is given no batch to read, so the follow-up neither uses the batch's results nor sends its requests at the normal price when the batch missed its deadline.

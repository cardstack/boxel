# ADR 011 remediation

Places where the code does not meet [ADR 011](../011-reveal-a-users-matrix-id-only-to-users-who-share-a-realm-with-them.md)
yet (ADR 001 §1.6).

- `packages/host/app/tools/invite-user-to-room.ts` (`InviteUserToRoomTool`)
  breaks §1.5. It invites any Matrix id to a room, with no check that the
  invitee shares a realm with the room's other end users.
- The homeserver configurations for staging and production are kept outside
  this repository, so no entry here can name them. They break §1.6 until each
  one sets the user directory, profile and invite settings that the templates
  under `packages/matrix/support/synapse/` set, and loads
  `boxel_invite_check.BoxelInviteCheck` under `modules:` with the
  `realm_server_url` of its realm server and a `shared_secret` equal to that
  realm server's `MATRIX_INVITE_CHECK_SECRET`.
  `.github/workflows/sync-synapse-assets.yml` copies
  `packages/matrix/support/synapse/modules/` to those homeservers, but each
  configuration still has to list the module.

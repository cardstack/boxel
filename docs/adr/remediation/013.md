# ADR 013 remediation

Places where the code does not meet [ADR 013](../013-settle-a-transcripts-scroll-anchor-in-the-render-pass-before-motion-measures.md)
yet (ADR 001 §1.6).

- `packages/choreo/src/run.ts`, a run compiled in a long task: §1.11. The first painted frame after a send still advances the follow by about 14% of its travel (19 px of 133 when the task before it took 87 ms): the run's clock counts part of that task despite the fresh-clock start.
- `packages/choreo/src/far.ts`, `runBarrier`: §1.21. Only the nearest scroller above each region is held. A scroller inside a region, with a participant in it flying past its end, is still clamped when the region measures.

# ADR 013 remediation

Places where the code does not meet [ADR 013](../013-settle-a-transcripts-scroll-anchor-in-the-render-pass-before-motion-measures.md)
yet (ADR 001 §1.6).

- `packages/choreo/src/far.ts`, `runBarrier`: §1.21. Only the vertical scroll of the nearest scroller `scrollerOf` finds above each region, or of the document, is held. A scroller inside a region, a horizontal scroll, and a `display: contents` element `scrollerOf` takes for a scroller although it doesn't scroll are still clamped when a region measures. Once a `@route` region has placed the window, the document isn't held for the regions that measure after it in the same pass.

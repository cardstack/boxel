# ADR 021 remediation

Places where the code does not meet [ADR 021](../021-run-boxels-oauth-provider-in-the-realm-server-with-opaque-resource-bound-tokens.md)
yet (ADR 001 §1.6). Each entry names a file by its path from the repository
root, in backticks, and the requirement it breaks.

- `packages/realm-server/lib/oauth-provider/serve.ts`
  (`registerOAuthProviderRoutes`) registers the authorization server's
  discovery document but none of the provider's endpoints, which breaks §1.1.
- `packages/realm-server/routes.ts` serves no protected-resource metadata for
  any resource, which breaks §1.3.
- `packages/realm-server/lib/oauth-provider/registry.ts` maps `POST /mcp` to
  both of `/mcp`'s scopes, but no route is registered there, which breaks
  §1.3.
- `packages/secure-origin/src/shell/pages.js` has no sign-in-and-consent,
  device-code or connected-apps page, which breaks §1.1.
- `packages/runtime-common/realm.ts` (`Realm.#verifySession`) refuses an OAuth
  token as an invalid JWT instead of looking it up, which breaks §1.5.
- `packages/realm-server/middleware/multi-realm-authorization.ts`
  (`multiRealmAuthorization`) refuses an OAuth token as an invalid JWT instead
  of looking it up, which breaks §1.5.
- `packages/realm-server/middleware/index.ts` (`jwtMiddleware`) refuses an
  OAuth token as an invalid JWT instead of looking it up, which breaks §1.5.

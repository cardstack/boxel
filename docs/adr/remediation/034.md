# ADR 034 remediation

Places where the code does not meet
[ADR 034](../034-keep-each-realms-history-in-a-sha-256-git-repo-named-by-its-permanent-registry-id.md)
yet (ADR 001 §1.6).

The repos are still written in the SHA-1 object format:

- `packages/realm-historian/src/git-objects.ts` (`hashObject`) names objects by
  their SHA-1, which breaks §1.1.

`packages/realm-historian/src/repo-format.ts`:

- `initRepo` creates a repo in the SHA-1 object format, which breaks §1.1.
- `updateMain` and `parseIncludesSuperseded` take 40-hex SHA-1 ids, which
  breaks §1.1.

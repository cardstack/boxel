# ADR 006 remediation

Places where the code does not meet [ADR 006](../006-grant-realm-permissions-per-realm-and-widen-them-only-with-a-policy.md)
yet (ADR 001 §1.6).

- `packages/runtime-common/realm.ts` (`handleAtomicOperations`,
  `upsertCardSource`, `upsertBinaryFile`, `removeCardSource`) breaks §1.3. A
  caller who isn't signed in is refused there, whatever grant opens a write
  to such a caller.

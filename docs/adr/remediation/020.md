# ADR 020 remediation

Places where the code does not meet
[ADR 020](../020-push-public-realm-changes-as-cacheable-http-invalidations.md)
yet (ADR 001 §1.6). Each entry names a file by its path from the repository
root, in backticks, and the requirement it breaks.

`packages/runtime-common/public-realm-events.ts`:

- `PublicRealmFeed` keeps its sequence in the memory of the process that
  serves the realm, so realm-server replicas each hold a separate sequence,
  and a change written through one replica never reaches a subscriber on
  another. Breaks §1.1 and §1.3.

# ADR 020 remediation

Places where the code does not meet
[ADR 020](../020-push-public-realm-changes-as-cacheable-http-invalidations.md)
yet (ADR 001 §1.6). Each entry names a file by its path from the repository
root, in backticks, and the requirement it breaks.

`packages/realm-server/node-realm.ts`:

- `broadcastRealmEvent` sends realm events only to Matrix rooms; no public
  feed is produced, sequenced or filtered. Breaks §1.1, §1.2 and §1.3.

`packages/runtime-common/realm.ts`:

- `cardJsonCacheControl` answers `public` only when the whole realm is
  world-readable, so a signed-out read a policy grant admits is `private`
  and no shared cache can serve it. Breaks §1.5.
- No card read can be addressed by revision. Breaks §1.5.

`packages/host/app/services/message-service.ts`:

- Only `matrix-service.ts` relays realm events into this service, so a
  session that isn't signed in receives none. Breaks §1.6.

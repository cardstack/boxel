# ADR 020 remediation

Places where the code does not meet [ADR 020](../020-do-the-assistants-workspace-work-in-one-sandboxed-script.md)
yet (ADR 001 §1.6).

- `packages/host/app/tools/send-ai-assistant-message.ts` (`run`) breaks §1.1:
  it offers the model a named patch tool for each attached card it can write.

`packages/host/app/tools/run-realm-code.ts`:

- `index.reindex`, `index.fullReindex` and `index.invalidate` break §1.6: a
  run may make any number of these calls.

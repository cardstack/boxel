# ADR 029 remediation

Places where the code does not meet [ADR 029](../029-charge-metered-usage-at-aws-unit-cost-times-a-margin-held-in-ssm-with-a-pricing-version-on-every-charge.md)
yet (ADR 001 §1.6).

- `packages/billing/billing-queries.ts` (`addToCreditsLedger`) breaks §1.6.
  An entry records only the user, amount, credit type and subscription
  cycle: no charge kind, realm or reference.
- `packages/billing/billing-queries.ts` (`spendCredits`) breaks §1.6. Its
  rows for one charge share no identity, so nothing stops a retry from
  charging again.
- `packages/billing/ai-billing.ts` (`spendUsageCost`) breaks §1.6. It charges
  with no charge kind, realm or reference.
- `packages/runtime-common/tasks/daily-credit-grant.ts` breaks §1.6. It
  inserts `daily_credit` rows into `credits_ledger` with no charge kind.
- `packages/realm-server/handlers/handle-add-credit.ts` breaks §1.6. It
  inserts into `credits_ledger` with no charge kind.

# ADR 032 remediation

Places where the code does not meet [ADR 032](../032-evaluate-browser-modules-in-the-browsers-module-loader.md)
yet (ADR 001 §1.6).

`packages/host/app/services/loader-service.ts`:

- The service as a whole (`loader`, `makeInstance`) breaks §1.1: the host page
  evaluates every realm module through the Loader.
- `resetLoader` breaks §1.4: each call that actually replaces the Loader
  discards every module it holds.
- `publish` breaks §1.3: the active Loader is published to a global so bundled
  modules can read it.
- `wasModuleFlushedForCodeChange` and `loadedOrFlushedModuleKeys` break §1.3:
  "was this module loaded" is answered from the map of a discarded Loader.

`packages/runtime-common/loader.ts`:

- `fetchModule` and `evaluateModuleInCurrentRealm` break §1.1: the browser path
  transpiles the module to AMD and `eval`s it in the page's realm.
- `moduleCacheKey` and `trimModuleIdentifier` break §1.2: a module is keyed by a
  folded spelling of its URL rather than the URL an import map resolves to.
- `shimModule`, `moduleShims`, and `cloneLoader` break §1.3: modules enter the
  map as values, with no URL and no fetch.
- `isModuleLoaded`, `loadedModuleKeys`, `getConsumedModules`, and
  `getKnownConsumedModules` break §1.3: the platform reads the module graph out
  of the Loader that is evaluating it.

Elsewhere:

- `packages/runtime-common/amd-transpile/index.ts` (`transpileAmd`) breaks
  §1.1: it exists to feed the Loader's `eval` in the page.
- `packages/runtime-common/loader-plugin.ts` and
  `packages/host/lib/import-meta-loader-plugin.cjs` break §1.3: they rewrite
  `fetch` and `import()` into `import.meta.loader`.
- `packages/runtime-common/bundled-module-loader.ts` breaks §1.3: a global holds
  the active Loader for modules the platform compiled.
- `packages/runtime-common/scoped-css.ts` (`maybeHandleScopedCSSRequest`) breaks
  §1.3: an inline scoped-CSS request is answered inside the page's fetch layer
  instead of at a URL the browser fetches.
- `packages/runtime-common/virtual-network.ts` (`addImportMap`, `resolveImport`)
  breaks §1.2: the import map lives in JS and its entries are handler functions
  rather than entries a browser installs.
- `packages/runtime-common/realm.ts` (`#compileModule`) breaks §1.2: a module is
  served at a URL whose body can change under it (`cache-control: public,
max-age=0` with an `ETag`), and carries its canonical path in
  `X-Boxel-Canonical-Path`.
- `packages/host/app/lib/externals.ts` (`shimExternals`),
  `packages/host/app/lib/bundled-base.ts` (`shimBundledBase`),
  `packages/host/app/tools/index.ts` (`shimHostTools`, `shimHostToolModule`), and
  `packages/runtime-common/package-shim-handler.ts` break §1.3: npm packages,
  host tools, and bundled base modules enter the module map as values, with no
  URL the import map names.
- `packages/host/app/services/network.ts` (`configureVirtualNetwork`) breaks
  §1.2 with its `@cardstack/boxel-icons/` import-map entry, which is a handler
  that rewrites the matched remainder, and breaks §1.3 with its `shimExternals`
  and `shimBundledBase` calls.
- `packages/host/app/lib/prerender-util.ts` (`transitiveModuleDeps`) breaks
  §1.3: dependency discovery reads the evaluating Loader.
- `packages/host/app/routes/module.ts` (`getConsumedModules`) breaks §1.3, and
  (`resetLoader`) breaks §1.4.
- `packages/base/card-api.gts`, `packages/base/card-serialization.ts`,
  `packages/base/code-ref.gts`, `packages/base/contains-many-component.gts`,
  `packages/base/links-to-editor.gts`, `packages/base/links-to-many-component.gts`,
  `packages/base/skill-frontmatter-field.gts`, and `packages/base/spec.gts`
  break §1.3: they read `import.meta.loader`.

Discarding the Loader to pick up changed modules, or to force a fresh
evaluation, breaks §1.4:

- `packages/host/app/resources/file.ts` (`onRealmInvalidation`, `writeTask`)
- `packages/host/app/services/card-service.ts` (`saveSource`)
- `packages/host/app/services/store.ts` (`rebuildForCodeChange`)
- `packages/host/app/routes/render.ts`
- `packages/host/app/components/card-prerender.gts`
- `packages/host/app/tools/evaluate-module.ts` (`run`)
- `packages/host/app/tools/instantiate-card.ts` (`run`)

Host tests that run in a browser and shim modules into the Loader break §1.3:

- `packages/host/tests/live-test.js`
- `packages/host/tests/helpers/adapter.ts`
- `packages/host/tests/helpers/identity-tags.ts`
- `packages/host/tests/unit/loader-test.ts`
- `packages/host/tests/unit/loader-parallel-prefetch-test.ts`
- `packages/host/tests/unit/virtual-network-reset-test.ts`
- `packages/host/tests/unit/amd-transpile-test.ts`
- `packages/host/tests/integration/components/markdown-preview-test.gts`
- `packages/experiments-realm/poster-board/poster-board.test.gts`

# ADR 032 remediation

Places where the code does not meet [ADR 032](../032-define-the-card-contract-as-the-boundary-between-card-code-and-its-runtime.md),
or the Card Contract it makes normative, yet (ADR 001 §1.6). Each entry names a
file by its path from the repository root, in backticks, and the requirement it
breaks. A Card Contract requirement is cited by chapter, as in "author API
§7.8".

Code in the base realm's author API modules (`card-api.gts`, `operations.ts`,
`field-component.gts`, `contains-many-component.gts`, the default templates)
may use platform-only members (Card Contract README, "The base realm"). The
entries below for those files are about what they expose to cards, or about a
host they depend on.

`packages/base/card-api.gts`:

- `mode` and `submode` on `CardContext` break §1.4: host UI vocabulary in the
  interface every card sees.
- `cardComponentModifier`, `markdownEmbedChooser`, and `loadRoomMedia` on
  `CardContext` break §1.5: host bridges on the interface every card reads
  (author API §10).
- `getCard` and `getCardCollection` beside `getCards`, `store.search`, and
  `searchResultsComponent` break §1.9: five routes to one query.
- `@editCard` and `@saveCard`, and `editCard`, `saveCard`, and `deleteCard` in
  `CardCrudFunctions`, break §1.9: no catalog card uses the template arguments,
  and saving and deleting are writes with their own path (author API §5.10).
- `Box` (exported from the module card authors import) breaks §1.5: a runtime
  reconciliation mechanism on the author-facing surface.
- `CardStore`'s diagnostic members (`queryLoadsInFlight`, `recentCardDocLoads`,
  `trackQueryLoad`, and their siblings) break §1.5.
- `capturesMeta` breaks §1.9: it repeats each slot's declared dimensions on
  every instance, and its `deviceScaleFactor` breaks §1.4 as a capture
  renderer's parameter.
- `cardInfo`'s `name`, `summary`, `theme`, `cardThumbnailURL`, and
  `cardThumbnail` break §1.9: a second name for each presentation member, and
  three sources for the thumbnail (author API §7.8).
- `static headerColor` breaks §1.4: one host's stack chrome, read only by
  `packages/host/app/components/operator-mode/stack-item.gts`.
- `icon` typed `ComponentLike<{ Element: SVGSVGElement }>` breaks §1.4: the
  author declares a component from one icon package instead of a reference the
  environment resolves.
- `resolvesQueryFieldsEagerly` breaks §1.3: a store can decline eager
  resolution without saying so, and a settle wait does not include the
  deferred query.
- `RESERVED_FIELD_NAMES` covers two members of the instance surface author API
  §7.8 lists, which breaks author API §7.8.
- `commandContext` (the pre-rename spelling kept beside `toolContext`) breaks
  §1.9: an alias with no sunset.
- `FileDef`'s `url` and `sourceUrl` break §1.9 and author API §12.5: three names
  for one deployment URL, stamped by
  `packages/runtime-common/index-runner/file-indexer.ts`.
- No author-facing accessor gives a query-backed relationship's total or whether
  its list is partial, which breaks author API §4.4. The total is kept in
  `packages/base/query-field-support.ts` (`seedTotal`) but not exposed.
- The type of `operations()` in `packages/base/operations.ts` is cast to `any`
  at every catalog call site, which breaks §1.3 in practice: the author API for
  invoking an operation is not usable as typed.

`packages/runtime-common/index.ts` (`Tool` exported as `Command`) and
`packages/host/app/tools/index.ts` (`@cardstack/boxel-host/commands/*` beside
`tools/*`):

- Two aliases with no sunset break §1.9. Catalog cards use only the old names.

`packages/host/app/lib/externals.ts` and `packages/host/app/tools/index.ts`:

- `@cardstack/runtime-common`, the host tools, and `@cardstack/boxel-host/lib/*`
  are reachable from card code by bare specifier, which breaks author API
  §1.11. (Third-party shims are not a gap against the contract: author API
  §1.10 allows them until package management exists.)
- `fallbackShim` stubs for `@cardstack/host/tests/helpers*`,
  `@cardstack/host/services/store`, `@cardstack/host/config/environment`, and
  `@ember/owner` resolve for every module, not only test modules, which breaks
  author API §1.5 and §1.11: an import outside a test reads `undefined` instead
  of failing.

`packages/host/tests/live-test.js`, and `shimModulesForLiveTests` in
`packages/host/app/lib/externals.ts`:

- Card tests run on the host's own test harness, and no testing API exists,
  which breaks author API §15. The 59 catalog test modules import the host's
  acceptance helpers, mock the Matrix client, and fetch host services with
  `getService`. Test modules are not kept out of indexing, which is why the
  helper stubs exist (author API §15.2).

`packages/runtime-common/constants.ts` (the `*ContextName` exports):

- Provide/consume context names importable by cards break §1.1 and §1.9: a
  sixth channel, and a second route to permissions, queries, and navigation.

`packages/runtime-common/formats.ts`:

- The `Format` union's `form` breaks §1.4: it is a menu value of the
  code-submode playground's format chooser
  (`packages/host/app/components/operator-mode/code-submode/playground/playground-panel.gts`,
  `packages/host/app/components/operator-mode/preview-panel/index.gts`), which
  render it as `edit`. No card can declare a `form` template.
- `metadata` in `fileDefFormats` but not in `formats` breaks §1.8:
  `isValidFormat('metadata')` is false while the file family accepts it.

`packages/runtime-common/search-doc-keys.ts` (`_title`, `_cardType`,
`_isCardInstanceFile`) and `packages/runtime-common/index-query-engine.ts`
(`generalSortFields`, `MATCH_RELEVANCE_SORT_KEY`):

- These break §1.4: index keys reachable from a query an author writes.
- `cardURL` in `generalSortFields` breaks §1.4: a sort by a URL that is not
  durable across deployments.

`packages/base/default-templates/file-def-edit.gts` and `FileDef.edit` in
`packages/base/card-api.gts`:

- A file def declares an `edit` template that `fileDefFormats` excludes, which
  breaks §1.3.

`packages/base/workspace.gts` and `packages/base/cards-grid.gts`:

- Filters on `_cardType` break §1.4: card-authored queries address the index's
  row layout.

`packages/base/default-templates/missing-template.gts`:

- It imports `switch-submode` from the host and passes `submode: 'code'`, which
  breaks §1.4: a card's default template drives the host's navigation.

`packages/base/command.gts` (`@field submode`):

- Host navigation vocabulary stored as card data breaks §1.4.

`packages/base/spec.gts`:

- A library card that passes `import.meta.loader` to three calls breaks runtime
  contract §2.6.

`eslint/ambient-clock-selectors.cjs` and `eslint/erasable-syntax-selectors.cjs`:

- Each is the only place its rule is stated, which breaks §1.6. Card Contract
  now states both rules; the rules' own messages still give a reason that does
  not apply to card code.

`eslint/data-test-selectors.cjs`:

- Its justification differs by build context, which breaks §1.4: whether
  `data-test-*` reaches a person is a rendering detail a card can currently
  depend on.

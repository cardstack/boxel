# ADR 017 remediation

Places where the code does not meet [ADR 017](../017-fit-toolbar-rows-with-layoutcontrol-not-per-app-css.md) yet (ADR 001 §1.6). Each entry names a file by its path from the repository root, in backticks, and the requirement it breaks. Write "No known gaps." when there are none.

- `packages/pretui/components/search-input.gts` breaks §1.3: its height reads `--pretui-field-h`, and LayoutControl doesn't map the row height onto it.
- `packages/pretui/components/button.gts` and `packages/pretui/components/icon-button.gts` break §1.3: neither reads `--pretui-row-h`, and LayoutControl doesn't map the row height onto `--pretui-button-h`.

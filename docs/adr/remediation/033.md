# ADR 033 remediation

Places where the code does not meet [ADR 033](../033-map-host-urls-to-a-realm-by-its-identity-and-resolve-them-before-any-other-route.md)
yet (ADR 001 §1.6). Each entry names a file by its path from the repository
root, in backticks, and the requirement it breaks.

- `packages/realm-server/handlers/handle-publish-realm.ts` breaks §1.2: it
  copies a realm in order to serve it.
- `packages/base/default-templates/head.gts` breaks §1.4: it renders no
  canonical link.
- `packages/realm-server/lib/index-html-injection.ts` breaks §1.4 and §1.5: it
  serves the stored head HTML unchanged, so the canonical link and `og:url`
  name the realm's URL, not its canonical host URL.
- `packages/realm-server/routes.ts` breaks §1.4: no route serves a realm's
  sitemap.
- `packages/realm-server/handlers/handle-claim-boxel-domain.ts` breaks §1.1:
  it stores a site-name claim against the realm's URL, not its id.
- `packages/realm-server/handlers/handle-get-boxel-claimed-domain.ts` breaks
  §1.1: it finds a site-name claim by the realm's URL.
- `packages/realm-server/handlers/handle-delete-realm.ts` breaks §1.1: it
  finds the deleted realm's site-name claims by its URL.

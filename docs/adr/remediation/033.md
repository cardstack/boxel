# ADR 033 remediation

Places where the code does not meet [ADR 033](../033-map-host-urls-to-a-realm-by-its-identity-and-resolve-them-before-any-other-route.md)
yet (ADR 001 §1.6). Each entry names a file by its path from the repository
root, in backticks, and the requirement it breaks.

- `packages/realm-server/lib/realm-routing.ts` (`findRealm`) breaks §1.2: it
  finds a realm only by its URL, and never looks up `realm_host_urls`.
- `packages/realm-server/handlers/handle-publish-realm.ts` breaks §1.2: it
  copies a realm in order to serve it.
- `packages/base/default-templates/head.gts` breaks §1.4: it renders `og:url`
  from the card's id, not the canonical host URL, and renders no canonical
  link.
- `packages/realm-server/lib/index-html-injection.ts` breaks §1.4: it serves
  the stored head HTML unchanged, so a request on a host URL gets the head
  that names the realm's URL.
- `packages/realm-server/routes.ts` breaks §1.4: no route serves a realm's
  sitemap.

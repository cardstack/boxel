# ADR 007 remediation

Places where the code does not meet [ADR 007](../007-keep-motion-a-reactive-layer-that-state-never-waits-on.md)
yet (ADR 001 §1.6).

- `packages/host/app/components/host-mode/stack.gts` breaks §1.6: when a
  card closes, `restoreScrollTop` reapplies its saved offset every 16 ms
  until it holds. When the uncovered card animates in, as it does in the
  narrow layout, an offset far down the card holds only once the scale-in
  has grown it back, so code outside an engine times the scroll against an
  animation.

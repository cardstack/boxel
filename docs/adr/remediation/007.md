# ADR 007 remediation

Places where the code does not meet [ADR 007](../007-keep-motion-a-reactive-layer-that-state-never-waits-on.md)
yet (ADR 001 §1.6).

- `packages/host/app/components/host-mode/stack-item.gts` breaks §1.1: it
  holds an `animationType` field that exists only for its opening animation,
  and its settled DOM keeps the `opening-animation` class, which it leaves
  off when testing, so the settled DOM differs from the DOM with motion off.
- `packages/host/app/components/pill-menu/index.gts` breaks §1.1: the menu
  collapses only on `animationend`.
- `packages/pretui/components/toaster.gts` breaks §1.1: a toast is removed on
  `animationend`, so with motion off it is never removed by its timer.

# ADR 049 remediation

Places where the code does not meet [ADR 049](../049-show-an-end-user-cost-only-as-the-boxel-credits-charged-never-as-a-unit-cost.md)
yet (ADR 001 §1.6). Each entry names a file by its path from the repository
root, in backticks, and the requirement it breaks. Write "No known gaps." when
there are none.

- `packages/host/app/lib/format-token-usage.ts` (`creditsForCost`, `formatCredits`) breaks §1.3: each turns a turn's `costUsd` into credits on the client.
- `packages/host/app/lib/format-token-usage.ts` (`formatTokenUsage`) breaks §1.2: it writes a turn's `costUsd` as dollars, which the `showTokens` line in `message/index.gts` shows as its `title`.
- `packages/host/app/components/ai-assistant/message/index.gts` (`tokenCredits`) breaks §1.3 and §1.4: a reply's credits come from the turn's `costUsd`.
- `packages/host/app/components/matrix/room.gts` (`conversationCredits`, and the session total beside the composer) breaks §1.3 and §1.4: the room's credits come from the turns' summed `costUsd`.
- `packages/host/app/lib/realm-runner/credits.ts` (`session.replyCredits`) breaks §1.3 and §1.4: the session's reply credits come from `creditsForCost(session.costUsd)`.
- `packages/ai-bot/lib/responder.ts` (the usage it writes into a reply's room event, typed by `packages/base/matrix-event.gts`) breaks §1.4: the event carries the turn's `costUsd`, which every member of the room can read.
- `packages/realm-server/handlers/handle-request-forward.ts` (`_request-forward`, through `forwardJsonResponse` in `packages/realm-server/lib/proxy-forward.ts`) breaks §1.4: it writes the provider's response to the caller unchanged, `usage.cost` included, and a card reads it through the `send-request-via-proxy` tool.

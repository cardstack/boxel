# ADR 016 remediation

Places where the code does not meet [ADR 016](../016-carry-a-matrix-events-oversized-structured-fields-as-media.md)
yet (ADR 001 §1.6).

- `packages/host/app/services/tool-service.ts` (`attachedFilesForToolResult`):
  a tool result lists every file a `run-realm-code` call wrote under
  `attachedFiles`, inline, so a call that writes about 120 files passes the
  limit. It should go through `externalizeOversizedFields` (§1.1). The
  readers restore any field already (§1.2).

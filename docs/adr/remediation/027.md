# ADR 027 remediation

Places where the code does not meet [ADR 027](../027-keep-an-automations-state-in-its-realm-and-commit-a-runs-writes-as-one-batch.md)
yet (ADR 001 §1.6).

`packages/runtime-common/realm.ts`:

- `removeCardSource`, `patchCardInstance`, `removeCard`, the `_operations`
  write entries and `_atomic` break §1.2. A run's write through them lands in
  the realm, not in the run's overlay. Only the card+source write and its
  octet-stream spelling stage into the overlay.
- The card+json read and the search routes break §1.3. A run reads a card's
  indexed version there, not the version it staged.

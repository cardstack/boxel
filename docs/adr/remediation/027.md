# ADR 027 remediation

Places where the code does not meet [ADR 027](../027-keep-an-automations-state-in-its-realm-and-commit-a-runs-writes-as-one-batch.md)
yet (ADR 001 §1.6).

- `packages/runtime-common/realm.ts` breaks §1.2 and §1.3. A run can't
  remove a card or file: `removeCard`, `removeCardSource` and a `delete`
  entry in `_operations` refuse a run's removal with 403
  `run-write-not-staged`, because an overlay row holds a file's bytes, with
  nothing to mark a staged removal. So the removal isn't staged (§1.2), and
  a search has no staged removal to omit (§1.3).
- `packages/runtime-common/realm.ts` breaks §1.3. Four reads answer a run
  with the realm's version of a card or file it staged, from the index:
  the card+json `HEAD` (`headCard`), the card+html read (`getCardHtml`), the
  file-meta+html read (`getFileMetaHtml`) and the markdown read
  (`getCardMarkdown`). A staged file has no index row and no rendering, so
  for a file only the run created they answer as if it doesn't exist.

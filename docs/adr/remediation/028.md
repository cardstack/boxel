# ADR 028 remediation

Places where the code does not meet [ADR 028](../028-define-an-automation-in-a-card-and-keep-its-payer-and-status-in-a-server-row.md)
yet (ADR 001 §1.6).

- `packages/runtime-common/automation-reconcile.ts` (`reconcileLostRun`) enqueues a lost run again for an automation waiting for key approval, which breaks §1.5.

# ADR 026 remediation

Places where the code does not meet [ADR 026](../026-give-an-automation-run-a-token-for-its-realm-alone-and-act-as-a-person-through-handleautomation.md)
yet (ADR 001 §1.6).

- `packages/runtime-common/realm.ts` (`handleAutomation`) breaks §1.3. It
  does not refuse a write once the run's `writes` cap is spent.
- `packages/runtime-common/realm.ts` (`handleAutomation`) breaks §1.5. It
  authorizes a batch as that user's request would be, which admits a writer
  through a policy grant, and it never checks direct write.
- `packages/realm-server/prerender/render-runner.ts` breaks §1.2. It hands a
  `run-command` tab its session through `localStorage['boxel-session']`,
  which page code can read, and that session is the `prepareRunCommand` auth
  for every realm the `runAs` user can reach.

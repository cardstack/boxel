# ADR 026 remediation

Places where the code does not meet [ADR 026](../026-give-an-automation-run-a-token-for-its-realm-alone-and-act-as-a-person-through-handleautomation.md)
yet (ADR 001 §1.6).

- `packages/runtime-common/realm.ts` (`handleAutomation`) breaks §1.5. It
  doesn't check that the run's identity is a direct writer when a call is
  admitted; only the commit (`commitRunOverlay`) checks it.
- `packages/runtime-common/tasks/run-automation.ts` (`runAutomationAttempt`)
  breaks §1.2. It starts a run without checking that no policy grant gives
  write to a module the run's cards load from the automation's realm,
  directly or through an import.

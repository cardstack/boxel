# ADR 031 remediation

Places where the code does not meet [ADR 031](../031-evaluate-a-scripts-bxl-in-a-worker-beside-quickjs-under-the-transform-profile.md)
yet (ADR 001 §1.6).

- `packages/host/app/lib/realm-runner/transform-worker.ts` breaks §1.4. Its
  `runtimeLimits` set only `maxMillis` and `maxSteps`, so BXL's `maxOutputs`
  and `maxOutputBytes` stay at their defaults.
